## Resumo sobre ODBC na linguagem Python

ODBC (Open Database Connectivity) é uma interface padrão para conectar programas a bancos de dados. Em Python, o pacote `pyodbc` permite usar drivers ODBC para executar comandos SQL no banco PostgreSQL, como inserir, atualizar e consultar dados diretamente via SQL.

---

## Resumo sobre ORM na linguagem Python e framework SQLAlchemy

ORM (Object-Relational Mapping) permite trabalhar com bancos relacionais usando objetos da linguagem Python. O framework SQLAlchemy mapeia tabelas para classes, facilitando operações como inserção, atualização e consultas sem precisar escrever SQL, tornando o código mais limpo e fácil de manter.
